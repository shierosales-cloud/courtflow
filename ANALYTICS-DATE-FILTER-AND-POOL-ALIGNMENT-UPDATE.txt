CourtFlow — Analytics Date Filter & Player Pool Alignment Update

Changes in this update:
- Centered all Player Pool table headers in Home and Current Session.
- Kept player names and player details left-aligned in both Player Pool tables.
- Centered the Sessions Attended values in the Most Attended Players Analytics table.

No database schema or existing Netlify function changes are required.
